# 🎓 Student Performance Analyzer

A **menu-driven CLI application** built using **Python and SQLite** to manage and analyze student data efficiently.

---

## 🚀 Features

* ➕ Add student details
* 📝 Add marks for students
* 📋 View student records in tabular format
* 📊 View marks data
* 📈 Calculate average marks
* 🏆 Identify top-performing student
* 🔗 Generate full report using SQL JOIN
* 🔍 Search student by ID
* 🗑️ Delete student records

---

## 🛠️ Technologies Used

* Python
* SQLite (SQL Database)

---

## 💡 Concepts Covered

* CRUD Operations (Create, Read, Update, Delete)
* SQL Queries (SELECT, INSERT, DELETE, JOIN, AVG, MAX)
* Database Integration with Python (`sqlite3`)
* Menu-driven CLI application

---

## ▶️ How to Run

1. Make sure Python is installed
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the following command:

```
python project.py
```
